# Guida degli elettrodomestici

Guida semplice per l'uso degli elettrodomestici di casa (microonde IKEA GÅTEBO, forno IKEA SPJUTBO,
piano cottura IKEA VILSTA, lavatrice Electroline), basata solo sui manuali d'uso.

- Contenuti: `src/data.js` · Interfaccia: `src/template.html` · Disegni: `src/img/`
- `python3 build.py` crea `index.html` (file unico, funziona offline) e la cartella `sito/`.
- Ogni push su `main` ripubblica automaticamente il sito su GitHub Pages.
